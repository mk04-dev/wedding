# Wedding Website - Lê Na & Tuấn Anh 💕✈️

Trang web thiệp cưới theo concept Passport/Boarding Pass với theme màu hồng pastel lãng mạn.

## Thông tin đám cưới

- **Cô dâu**: Nguyễn Thị Lê Na
- **Chú rể**: Đặng Tuấn Anh
- **Ngày cưới**: 09/03/2026 (Chủ nhật, 21 tháng 01 Âm lịch - Bính Ngọ)
- **Nhà gái**: 16h05 - Xã Nghĩa Giang, Tĩnh Quảng Ngãi
- **Nhà trai**: 17h30 - Phường An Lạc, TP. Hồng Ngự, Đồng Tháp

## Cài đặt

```bash
npm install
```

## Phát triển

```bash
npm run dev
```

Mở http://localhost:1234

## Build cho production

```bash
npm run build
```

Kết quả trong folder `dist/`

## Deploy

Push lên GitHub và kết nối với Vercel để tự động deploy.

## Tech Stack

- Parcel bundler
- Vanilla HTML/CSS/JavaScript
- AOS.js (scroll animations)
- FlipDown.js (countdown timer)
- GLightbox (photo gallery)
- Leaflet.js (interactive map)
